# Password Strength Checker

A simple Python cybersecurity project that checks the basic strength of a password.

## Objective

The goal of this project is to learn basic password-security concepts and Python programming by creating a local password-strength checker.

## Features

The program checks whether a password:

* Has at least 8 characters
* Contains an uppercase letter
* Contains a lowercase letter
* Contains a number
* Contains a special character

It then gives the password a score from 0 to 5 and classifies it as Weak, Moderate, or Strong.

## Technologies Used

* Python 3
* Linux Terminal
* Git
* GitHub

## How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Enter the project directory:

```bash
cd password-strength-checker
```

Run the program:

```bash
python3 password_checker.py
```

## Security Note

This project is for educational purposes. Passwords entered into the program are not stored or transmitted.
